# 🧭 Kompas

IP-based tracking and geolocation analysis tool.

Kompas is a lightweight IP intelligence tool that retrieves and organizes publicly available geolocation data associated with user connections. It provides structured network context such as ISP, ASN, country, and approximate location.

# 🚀 Features

# 🌍 Detects public IP address

# 🏢 Identifies ISP (Internet Service Provider)

# 🗺️ Retrieves country, region, and approximate city

# 🧩 Extracts ASN and provider organization

# 📊 Structured output for monitoring and analysis

# ⚡ Lightweight and fast response

# 🛠️ How It Works

Kompas queries public IP geolocation databases and transforms raw network metadata into structured, readable information.

The system does not access private data.
All information is derived from publicly available IP registry sources.

# ⚠️ Location data is approximate and based on ISP registration, not exact physical user location.

# 📦 Use Cases

Traffic origin analysis

Access monitoring

Basic network observability

Educational purposes

Security research context

# 🧠 Technical Overview

Kompas performs:

Public IP detection

External API request to geolocation provider

Structured parsing of response

Presentation of ISP, ASN, and regional metadata

# ⚖️ Disclaimer

Kompas uses publicly available IP geolocation services.
Results are approximate and should not be considered precise user tracking.

This tool is intended for monitoring, analytics, and research purposes only.
